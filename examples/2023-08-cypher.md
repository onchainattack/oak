# Cypher — sub-account isolation switch not tracked by the master account, plus a margin-check gap, drained a Solana futures DEX — Cypher / Solana — 2023-08-07

**Loss:** **~\$1M**: about 38,530 SOL and \$123,184 USDC (\$1,035,203 in total), per Solscan data cited by [crypto.news](https://crypto.news/cypher-protocol-freezes-smart-contract-amid-1m-exploit/) and [The Block](https://www.theblock.co/news/ecosystems/2024-05-14-cypher-protocol-contributor-admits-to-taking-and-gambling-funds-recovered-from-exploit-294459). Recovery: the Cypher team froze \$600,000 of the stolen funds on centralized exchanges and set up a redemption contract for users ([The Block](https://www.theblock.co/news/ecosystems/2024-05-14-cypher-protocol-contributor-admits-to-taking-and-gambling-funds-recovered-from-exploit-294459)).

**OAK Techniques observed:** **OAK-T9.016** (Contract Accounting / State-Invariant Flaw — *primary*). Per [Halborn](https://www.halborn.com/blog/post/explained-the-cypher-protocol-hack-august-2023): a primary account (`CypherAccount`) caches data for its sub-accounts, which are cross-collateralized by default; an error when a sub-account switched to isolated mode meant the master account did not track the change; a second error in the margin checks before borrowing, with oracle price feeds not yet active, let users borrow when they should not have been able to; the attacker repeated this across multiple primary accounts. See [`techniques/T9.016-contract-accounting-state-invariant-flaw.md`](../techniques/T9.016-contract-accounting-state-invariant-flaw.md).

**Attribution:** **unattributed.** No opened source names the attacker. The earlier version of this file said the attacker called themselves "Hailey", was arrested in January 2025 and was indicted by the DOJ; no opened page reports any of that, so it is removed. The later insider theft from the redemption contract is a separate incident, see [`2024-05-cypher-contributor-redemption-contract-theft.md`](2024-05-cypher-contributor-redemption-contract-theft.md).

**Key teaching point:** **When a master account caches sub-account state, every mode switch must update the cache, and the margin check must not run on cached or missing data.** Both gaps had to line up per [Halborn](https://www.halborn.com/blog/post/explained-the-cypher-protocol-hack-august-2023), and an audit before launch could have caught them.

## Summary

On 2023-08-07 Cypher, a Solana-based decentralized futures exchange, announced an exploit or security incident, froze its smart contract and asked the hacker to talk ([CoinDesk](https://www.coindesk.com/business/2023/08/07/solana-based-cypher-protocol-experiences-exploit-freezes-smart-contract/)). Solscan data showed roughly 38,530 SOL and 123,184 USDC taken, and about 30,000 USDC sent to a Binance Solana USDC address ([crypto.news](https://crypto.news/cypher-protocol-freezes-smart-contract-amid-1m-exploit/)). Halborn published the mechanism on 2023-08-15 ([Halborn](https://www.halborn.com/blog/post/explained-the-cypher-protocol-hack-august-2023)). Cypher later froze \$600,000 on centralized exchanges and opened a redemption contract ([The Block](https://www.theblock.co/news/ecosystems/2024-05-14-cypher-protocol-contributor-admits-to-taking-and-gambling-funds-recovered-from-exploit-294459)).
