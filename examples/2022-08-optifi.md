# OptiFi — operator ran `solana program close` on the live mainnet program, locking all funds — OptiFi / Solana — 2022-08-29

**Loss:** **~\$661K** in USDC locked in the program's PDAs, not stolen ([Decrypt](https://decrypt.co/108585/solana-defi-exchange-optifi-bricks-itself-loses-661k); [The Block](https://www.theblock.co/post/166445/optifi-locks-up-661000-by-accidentally-shutting-itself-down), which cites DefiLlama for the total value locked). OptiFi said about 95% of the locked funds belonged to a member of its own team, and CoinDesk concluded that customer assets may have been only about \$33,000 ([Decrypt](https://decrypt.co/108585/solana-defi-exchange-optifi-bricks-itself-loses-661k); [CoinDesk](https://www.coindesk.com/business/2022/08/30/solana-based-defi-protocol-optifi-loses-661k-in-programming-blunder/)). OptiFi said it would return all users' deposits and settle positions manually, a process it estimated at two weeks ([CoinDesk](https://www.coindesk.com/business/2022/08/30/solana-based-defi-protocol-optifi-loses-661k-in-programming-blunder/); [Decrypt](https://decrypt.co/108585/solana-defi-exchange-optifi-bricks-itself-loses-661k)). Whether and when the refunds were paid is undisclosed in the pages OAK opened.

**OAK Techniques observed:** **OAK-T9.004** (Access-Control Misconfiguration — *primary, closest available fit*). No attacker was involved. The team's own deployer used the program's upgrade authority to run a destructive command that nothing in the process gated; the technique page's definition is about a contract accepting a caller it should have rejected, so the fit is by control surface (a single actor able to run an irreversible privileged operation), not by mechanism. See [`techniques/T9.004-access-control-misconfiguration.md`](../techniques/T9.004-access-control-misconfiguration.md).

**Attribution:** **unattributed** — self-disclosed operator error, no attacker ([Decrypt](https://decrypt.co/108585/solana-defi-exchange-optifi-bricks-itself-loses-661k)).

**Key teaching point:** **Make irreversible program operations impossible for one person to run alone.** OptiFi's own remedy was a peer-surveillance process in which at least three people review the deployer's steps for future deployments ([The Block](https://www.theblock.co/post/166445/optifi-locks-up-661000-by-accidentally-shutting-itself-down); [Decrypt](https://decrypt.co/108585/solana-defi-exchange-optifi-bricks-itself-loses-661k)). OptiFi also asked Solana core developers for more documentation of the command and an extra confirmation step before it executes ([Decrypt](https://decrypt.co/108585/solana-defi-exchange-optifi-bricks-itself-loses-661k)).

## Summary

OptiFi was a Solana options-trading DEX that had launched on mainnet earlier in August 2022 ([Decrypt](https://decrypt.co/108585/solana-defi-exchange-optifi-bricks-itself-loses-661k)). The team was upgrading its mainnet program. The upgrade ran longer than expected, which the team put down probably to Solana network congestion, so they aborted it; the aborted upgrade had already created an intermediary account. To reverse that account's creation they ran `solana program close`, which permanently closes the program and sends the SOL in the buffer account to a recipient wallet. The team later said they did not fully understand the impact and risk of the command ([The Block](https://www.theblock.co/post/166445/optifi-locks-up-661000-by-accidentally-shutting-itself-down)). The result was a closed mainnet program and funds nobody could move ([CoinDesk](https://www.coindesk.com/business/2022/08/30/solana-based-defi-protocol-optifi-loses-661k-in-programming-blunder/)).

OptiFi published its incident report on 2022-08-29 (the date is in the report's URL, as noted by [The Block](https://www.theblock.co/post/166445/optifi-locks-up-661000-by-accidentally-shutting-itself-down)); the press coverage is dated 2022-08-30. OAK could not open the report itself (see references), so the mechanism here is as relayed by three news outlets.

Recovery path: The Block reported that the funds stay locked unless Solana validators agree to a patch that makes the program recoverable, and that a contributor to Jump Crypto's Firedancer client had proposed such a patch on Solana's GitHub, which still needed technical review and approval by most validators ([The Block](https://www.theblock.co/post/166445/optifi-locks-up-661000-by-accidentally-shutting-itself-down)). OptiFi also said it planned a new version of the program ([Decrypt](https://decrypt.co/108585/solana-defi-exchange-optifi-bricks-itself-loses-661k)).
