# EasyFi — admin MetaMask key taken from the founder's machine, EASY tokens and pool liquidity drained — EasyFi / Polygon — 2021-04-19

**Loss:** 2.98 million EASY tokens plus about \$6M in USDC, DAI and USDT removed from liquidity pools, per [Halborn](https://halborn.com/explained-the-easyfi-hack-april-2021/) and [CoinDesk](https://www.coindesk.com/markets/2021/04/20/defi-protocol-easyfi-reports-hack-loss-of-over-80m-in-funds/). Headline totals differ by pricing: CoinDesk says over \$80M (EASY at about \$25), Halborn about \$81M, [Rekt](https://rekt.news/easyfi-rekt) \$6M in stablecoins and about \$53M in EASY. Rekt says the 2.98M EASY is about 30% of total supply. **Recovery:** none reported on the pages opened. The founder offered a \$1M reward for the return of all funds ([CoinDesk](https://www.coindesk.com/markets/2021/04/20/defi-protocol-easyfi-reports-hack-loss-of-over-80m-in-funds/)); a hard fork to recover funds was in the works per the same article.

**OAK Techniques observed:** **OAK-T11.014** (Operator Privileged-Key Compromise — *primary*). The attacker obtained the keys of the admin MetaMask account and used the admin authority as the contracts allowed; the founder said the smart contracts were not exploited ([CoinDesk](https://www.coindesk.com/markets/2021/04/20/defi-protocol-easyfi-reports-hack-loss-of-over-80m-in-funds/)). Rekt says the single admin key could drain all liquidity with no timelock ([Rekt](https://rekt.news/easyfi-rekt)). See [`techniques/T11.014-operator-privileged-key-compromise.md`](../techniques/T11.014-operator-privileged-key-compromise.md). **OAK-T15.003** (Operator-Endpoint Compromise — per Halborn): a malicious version of MetaMask was injected into a computer used for official project transfers ([Halborn](https://halborn.com/explained-the-easyfi-hack-april-2021/)). How that machine was first compromised is not stated.

**Attribution:** **unattributed.** No source opened names the attacker. The receiving wallet is [`0x83a2EB63B6Cc296529468Afa85DbDe4A469d8B37`](https://etherscan.io/address/0x83a2EB63B6Cc296529468Afa85DbDe4A469d8B37) ([CoinDesk](https://www.coindesk.com/markets/2021/04/20/defi-protocol-easyfi-reports-hack-loss-of-over-80m-in-funds/), [Rekt](https://rekt.news/easyfi-rekt)).

**Key teaching point:** **Put admin authority behind a multisig and a timelock, and keep the keys off any machine that can be tampered with.** Per Rekt a single admin key could drain all liquidity with no timelock, and per Halborn the machine holding it was used rarely and had been offline for over a week before the attack, so the response was delayed ([Rekt](https://rekt.news/easyfi-rekt), [Halborn](https://halborn.com/explained-the-easyfi-hack-april-2021/)).

## Summary

EasyFi is a DeFi lending protocol on Polygon. On 2021-04-19 the attacker used the admin MetaMask account to move 2.98 million EASY tokens and remove about \$6M of stablecoins from liquidity pools ([CoinDesk](https://www.coindesk.com/markets/2021/04/20/defi-protocol-easyfi-reports-hack-loss-of-over-80m-in-funds/), [Halborn](https://halborn.com/explained-the-easyfi-hack-april-2021/)). Founder Ankitt Gaur's blog post said the private keys to the admin MetaMask account were compromised through his computer and that the contracts were not exploited ([CoinDesk](https://www.coindesk.com/markets/2021/04/20/defi-protocol-easyfi-reports-hack-loss-of-over-80m-in-funds/)). Rekt quotes the founder saying the compromised machine "was not used for daily operations and is used solely for the purpose of official transfers" ([Rekt](https://rekt.news/easyfi-rekt)). EasyFi suspended deposits and withdrawals, which per CoinDesk stopped the hacker moving the stolen tokens out of the wallet.

An earlier version of this file named a different founder, gave an EZ token with about 6M drained, and described a sale of the stolen tokens on Uniswap and QuickSwap with an 80% price fall and an EasyFi V2 compensation framework. None of that is on a page opened in the 2026-11 source pass, and it is removed. Rekt reports the price fell about 20% in the first 24 hours because the hacker had not yet sold.
